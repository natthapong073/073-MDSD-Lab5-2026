# บันทึกเหตุผลการออกแบบฟีเจอร์ (Lab 5 - Section 5)

## 1. ฟีเจอร์ช่องค้นหาสินค้า (Search Box)
- **ชนิดของ State ที่เลือก:** Ephemeral State (Local State ด้วย `setState`)
- **เหตุผล:** ค่าคำค้นหาใช้งานและแสดงผลเฉพาะภายในหน้าจอ Home เท่านั้น ไม่มีหน้าจออื่นในแอปพลิเคชันที่ต้องใช้ข้อมูลร่วมกัน จึงเลือกใช้เครื่องมือที่เบาและเหมาะสมที่สุดโดยไม่ต้องประกาศเป็น App State

## 2. ฟีเจอร์ปุ่มล้างรายการโปรดทั้งหมด (Clear All Favorites)
- **การใช้งาน Context:**
  - ใช้ `context.watch<FavoritesModel>()` ในระดับ Widget Build เพื่อตรวจสอบสถานะ `savedItems.isNotEmpty` สำหรับเปิด/ปิดการแสดงผลของปุ่มล้างข้อมูลและอัปเดตจำนวนสินค้า
  - ใช้ `context.read<FavoritesModel>()` ภายในเหตุการณ์ปุ่มกดและ Dialog เพื่อเรียกใช้คำสั่ง `clear()` โดยไม่ทำให้ Widget ต้อง Rebuild โดยไม่จำเป็น
